# Pharmacy Inventory & Expiry Management System

C++ Object-Oriented Architecture & Implementation

A menu-driven console application to manage pharmacy stock and prevent the sale of expired medicines.

## Features
- Add medicines with validation (no duplicate IDs or invalid dates)
- Display all medicines
- Search medicine by ID
- Sell medicine with automatic billing (blocks expired stock)
- Expiry report of all expired medicines
- Update stock and delete records

## Tech Stack
- C++ (OOP: classes, objects, constructors, encapsulation)
- STL: vector, string
- <ctime> for today's date in expiry checks
- Compiler: g++

## How to Run
g++ HCL_project.cpp -o pharmacy
./pharmacy
